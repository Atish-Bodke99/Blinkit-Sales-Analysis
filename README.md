📊 Blinkit Sales Analysis Dashboard
🚀 Project Overview

This project focuses on analyzing Blinkit grocery sales data using Power BI to generate meaningful insights and support data-driven decision-making. The dashboard provides an interactive way to explore sales performance across different categories, outlets, and locations.

🎯 Objectives
Analyze overall sales performance
Identify top-performing product categories
Understand customer preferences
Evaluate outlet performance
Detect sales trends over time
🛠️ Tools & Technologies Used
Power BI
Microsoft Excel
DAX (Data Analysis Expressions)
📂 Dataset
Blinkit Grocery Dataset
Contains information about:
Item Type
Sales
Rating
Outlet Type
Outlet Size
Location
📊 Key Performance Indicators (KPIs)
💰 Total Sales: $1.20M
📈 Average Sales: $141
⭐ Average Rating: 3.9
📦 Number of Items: 8523
🔍 Key Insights
Low fat products generated higher sales compared to regular items
Fruits and vegetables are the top-selling category
Seafood is the least selling category
Medium-sized outlets contribute the highest revenue
Tier 3 locations generate maximum sales
Sales peaked in the year 2018
💡 Business Recommendations
Focus marketing strategies on low-fat products
Increase inventory for high-demand categories like fruits & vegetables
Improve sales strategies for low-performing categories like seafood
Expand operations in Tier 3 locations
Optimize performance of large outlets
📊 Dashboard Features
Interactive filters and slicers
Category-wise and outlet-wise analysis
Time-based sales trends
KPI summary cards
